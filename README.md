# QuantAI Solutions - Applied Inference & AI Engineering

Independent AI & Inference Engineering consultancy founded in India. I build methods that read large amounts of messy business text and turn it into structured, evidence-backed findings you can verify.

## What I Work On
- **Structured Extraction & Hypothesis Testing:** Turning unstructured documents into structured records and testing hypotheses against them
- **LLM Evaluation & Benchmarking:** Comparing models and tools on the same labelled data for agreement, consistency, and failure modes
- **Deterministic Verification Pipelines:** Hybrid workflows where scripts handle counting, quote verification, and arithmetic, while models handle reading
- **Cost-Efficient Funnel Designs:** Multi-stage pipelines using rule-based filters first, lightweight models next, and frontier models only on high-value candidates

## Tools & Stack
Python, SQL, LLM APIs, Embeddings, Text Classification, Evaluation Frameworks, Data Pipelines

## Engineering Principles
- Every claim traces back to a verifiable source
- Counts and aggregations come from deterministic scripts/tables, never from a model's own arithmetic
- Test small, measure drift across runs, and scale reliably
